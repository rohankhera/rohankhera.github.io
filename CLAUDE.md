# rohankhera.com — maintenance notes

Personal site for Rohan Khera, MD, MS. One static page on GitHub Pages, served from `main` with the custom domain in `CNAME`. No build step, no framework, no JavaScript, no third-party requests. `.nojekyll` tells GitHub to serve the files exactly as they are.

## Where things live
- `index.html` — all the words. Content only; each section has a comment saying how to add a row.
- `assets/site.css` — all the styling.
- `assets/fonts/` — Spectral and IBM Plex Sans, self-hosted (SIL Open Font License; licence files alongside).
- `assets/ecg.svg` — the rhythm-strip tile in the header, generated by `tools/make_ecg.py`.
- `headshot.jpg` — 640×800 colour portrait. The page shows it in black and white via CSS.
- `og-image.jpg`, `assets/apple-touch-icon.png` — share card and phone icon, generated by `tools/make_og.py` from `tools/og.html`.
- `404.html`, `robots.txt`, `sitemap.xml`, `CNAME`, `.nojekyll` — hosting plumbing. Never delete `CNAME` or `.nojekyll`.

## Design, and what to preserve
- The idea: an ECG printout. White paper, black ink, the rose grid, and ballpoint blue for links. The header strip is lead II in sinus rhythm at true paper scale (25 mm/s, 10 mm/mV, 1 mm = 4px) with a 1 mV calibration pulse. It records once on load; that is the only motion on the page.
- The strip is the one decorative element. Everything else stays quiet: no cards, chips, icons, shadows, gradients, or extra animation.
- Type: Spectral (light for the name and lede, regular for text, italic for side headings and journal names); IBM Plex Sans only for years, navigation, and small print. Sentence case for labels; no all-caps, no letter-spaced labels, no middle-dot separators.
- If the waveform is ever changed, keep it physiologically plausible. Cardiologists read this page.
- Colours and sizes are variables at the top of `assets/site.css`; dark mode is the second block.

## Ground rules
- Content must be factual and supplied by Rohan. Do not invent awards, titles, publications, or links. Check that every new link opens.
- Degrees are written "MD, MS" everywhere (title, heading, footer, share tags, JSON-LD).
- When an edit is requested, make that change; do not rewrite surrounding copy.
- Work on a branch and open a pull request; Rohan merges. The live site updates a minute or two after merge.

## Annual update checklist
1. Roles: titles current. Also update `jobTitle` in the JSON-LD block in `<head>`.
2. Recognition: add new awards, newest first.
3. Selected work: about six papers, newest first; each link opens.
4. Consulting: description still matches the engagements Rohan takes.
5. Contact: email is the one he wants inquiries sent to; profile links open.
6. Footer: change "Updated <Month Year>"; change `lastmod` in `sitemap.xml`.
7. If the name line or photo changed, run `python3 tools/make_og.py`.
8. Look at it at desktop width, phone width (~390px), and in dark mode before opening the pull request. Serve it locally (`python3 -m http.server`) rather than opening the file, or the strip will not draw.
